============================================================
COMMANDS: Ablation Stages 4–6 (Training + Evaluation)
Repository: Master-Thesis_semantic-adverse-segmentation-thesis
Code root: mask2former_/
============================================================

Prerequisites:
-------------
(1) Activate your environment:
    conda activate mask2former-adverse

(2) Export dataset paths:
    export CS_ROOT=/path/to/datasets/cityscapes
    export ACDC_ROOT=/path/to/datasets/ACDC

(3) Run all commands from:
    cd mask2former_

------------------------------------------------------------

NOTE:
-----
• Batch size is fixed to 3 for both training and evaluation.
• Dataset evaluation modes:
    - Cityscapes → mode 11
    - ACDC        → mode 21

------------------------------------------------------------
Ablation Stage 4
Cityscapes-only baseline (Mask2Former)
------------------------------------------------------------

Checkpoint:
-----------
best_mask2former_cityscapes_only_os16.pth

Script:
-------
mask2former_/Scripts_Extra/main_mask2former_cityscapes_only.py

About:
------
Cityscapes-only Mask2Former baseline (no ACDC).
Used to establish clear-weather performance before any
adverse-condition adaptation.

-----------------------
[Stage 4 - TRAIN] Cityscapes
-----------------------

cd mask2former_

CUDA_VISIBLE_DEVICES=0 \
python Scripts_Extra/main_mask2former_cityscapes_only.py \
  --mode 0 \
  --dataset cityscapes \
  --data_root_cs "$CS_ROOT" \
  --num_classes 19 \
  --output_stride 16 \
  --crop_size 640 \
  --batch_size 3 \
  --total_itrs 90000 \
  --lr 1e-5 \
  --loss_type cross_entropy

-----------------------
[Stage 4 - EVAL] Cityscapes (overall)
-----------------------

CUDA_VISIBLE_DEVICES=0 \
python Scripts_Extra/main_mask2former_cityscapes_only.py \
  --mode 11 \
  --dataset cityscapes \
  --test_batch_size 3 \
  --num_classes 19 \
  --output_stride 16 \
  --crop_size 640 \
  --ckpt checkpoints/best_mask2former_cityscapes_only_os16.pth

-----------------------
[Stage 4 - EVAL] ACDC (overall)
-----------------------

CUDA_VISIBLE_DEVICES=0 \
python Scripts_Extra/main_mask2former_cityscapes_only.py \
  --mode 21 \
  --dataset ACDC \
  --data_root_acdc "$ACDC_ROOT" \
  --test_batch_size 3 \
  --num_classes 19 \
  --output_stride 16 \
  --crop_size 640 \
  --ckpt checkpoints/best_mask2former_cityscapes_only_os16.pth
